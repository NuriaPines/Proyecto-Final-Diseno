# 👗✨ WEREABLE ✨👕

Bienvenida a **WEREABLE**, un proyecto final de la asignatura **Diseño Web** 🖥️🎨  
Se trata de una **página web de venta de ropa** inspirada en el estilo de marcas como **H&M**, con un diseño moderno, limpio y centrado en la experiencia de la usuaria.

---

## 🛍️ ¿Qué es WEREABLE?

**WEREABLE** es una tienda online de moda que ofrece:
- Ropa actual y accesible 👚
- Un diseño visual atractivo ✨
- Navegación intuitiva 🧭
- Enfoque responsive para distintos dispositivos 📱💻

El objetivo del proyecto es aplicar los conocimientos adquiridos en **diseño web**, tanto a nivel visual como estructural.

---

## 🎯 Objetivos del proyecto

- Diseñar una interfaz moderna y funcional 🎨
- Simular una experiencia real de e-commerce 🛒
- Aplicar buenas prácticas de maquetación web 🧩
- Crear una web clara, ordenada y fácil de usar 🤍

---

## 🛠️ Tecnologías utilizadas

- 🧱 **HTML5**
- 🎨 **CSS3**
- ⚙️ **JavaScript**
- 📐 Diseño responsive
- 💡 Inspiración en e-commerce reales de moda
